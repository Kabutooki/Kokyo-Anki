
【演習操作】
問題演習中に必要な操作は4択の選択だけです。回答すると正誤が短時間表示され、その後は自動で次の問題へ進みます。前へ／次へボタンや回答後の自己評価操作はありません。

GitHub Pages向けの詳しい手順は README.md を参照してください。


## v6 自動遷移修正
- 4択を選ぶと、正解時は約0.8秒、不正解時は約1.4秒後に自動で次の問題へ進みます。
- 学習履歴の端末保存に失敗した場合でも、演習と自動遷移は継続します。
- Service Workerをv6に更新し、GitHub Pages更新後に古い画面が残りにくいよう更新確認を強化しました。
- 更新時は `index.html` と `sw.js` を含む全ファイルを置き換えてください。公開後、Safariで一度サイトを開いてからホーム画面版を再起動してください。
