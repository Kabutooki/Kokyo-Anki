# 公共一問一答 PWA — 全面点検 v8

『公共一問一答』を4択形式で学習するPWAです。重要度別・分野別学習、検索、シャッフル、学習履歴保存に対応しています。

## 演習操作
問題演習中に必要な操作は **4択の選択だけ** です。回答すると正誤を短時間表示し、自動で次の問題へ進みます。2回連続正答で自動的に「習熟」、不正解で連続正答数は0に戻ります。

- J.S.ミルの引用問題、シビリアン・コントロール、四苦、SNSなど、PDF解析時に回答項目の境界や表記が崩れた箇所を修復しました。

## GitHub Pages で更新する手順
1. このフォルダの中身を、GitHub Pages 用リポジトリのルートに上書きアップロードします。
2. `index.html` と `sw.js` を含む **全ファイル** をコミットします。
3. Pages のデプロイ完了後、iPhoneの Safari で公開URLを一度開きます。
4. その後、ホーム画面版PWAを完全終了して再起動します。
5. 旧画面が残る場合のみ、ホーム画面アイコンを削除してSafariから再度「ホーム画面に追加」してください。

公開URLは通常 `https://<ユーザー名>.github.io/<リポジトリ名>/` です。


## v9 誤答選択肢の全面再設計
- 全1,925問について、誤答3個を事前計算してカードデータに固定しました。端末上で無関係語をランダム生成しません。
- 誤答語はすべて『公共一問一答』内に実際に登場する解答語から選んでいます。外部知識で新しい用語を捏造していません。
- 同一分野、設問文の類似度、語の種類（人物・法律・権利・条約・機関・著書・事件・場所など）、語尾（「〜原則」「〜法」「〜権」など）を組み合わせて候補を選びます。
- 複数回答問題は、翻訳・別名の組は対応関係を崩さず、列挙問題は原則として正答の一部だけを同系統語に置き換えた「紛らわしい近接誤答」にしました。
- 4択内の重複、正答と誤答の一致、複数回答の項目数不一致を全問検査しています。
- Service Worker は v9 です。
