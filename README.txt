# 公共一問一答 PWA — セッション演習 v24

『公共一問一答』を4択形式で学習するPWAです。重要度別・分野別学習、検索、シャッフル、学習履歴保存に対応しています。

## 演習操作
問題演習中に必要な操作は **4択の選択だけ** です。回答すると正誤を短時間表示し、自動で次の問題へ進みます。2回連続正答で自動的に「習熟」、不正解で連続正答数は0に戻ります。

## GitHub Pages で更新する手順
1. このフォルダの中身を、GitHub Pages 用リポジトリのルートに上書きアップロードします。
2. `index.html`、`app.js`、`cards.json`、`sw.js` を含む **全ファイル** をコミットします。v21以降では教材データを `cards.json` に分離しているため、旧版の `index.html` だけを更新する方法は使えません。
3. Pages のデプロイ完了後、iPhoneの Safari で公開URLを一度開きます。
4. その後、ホーム画面版PWAを完全終了して再起動します。
5. v13以前から更新する場合、最初の起動後に一度PWAを完全終了して再起動してください。旧画面が残る場合のみ、ホーム画面アイコンを削除してSafariから再度「ホーム画面に追加」してください。学習履歴は旧 `localStorage` からIndexedDBへ自動移行します。

公開URLは通常 `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

## v22 意味ベクトル弱点復習
- 全1,925問に **48次元の意味ベクトル** を事前付与しました。方式は、日本語の文字n-gram TF-IDFを48次元へTruncated SVDしたローカルな潜在意味ベクトルです。実行時に外部APIへ送信しません。
- 各問題に、48次元ベクトル、意味的近傍24問、意味クラスタ、可視化用2次元座標を保持します。
- 誤答した問題の弱点を、その問題だけで終わらせず、意味的近傍へ重み付きで伝播させます。
- 実際に選んだ誤答が別問題の正答語と一致する場合、その概念側にも強い弱点信号を与えます。これにより「控訴→上告」のような混同を概念空間上でも利用します。
- 復習優先度は、**意味ホット度 × 入試重要度 × 現在の学習状態**で補正します。
- 新しい「意味弱点」モードでは、ホットな領域を重点的に出しつつ、同一クラスタが3問以上連続しないよう領域間を分散します。
- 「弱点マップを見る」から、意味空間のホットエリアを確認できます。色が濃いほど誤答・混同が集中している領域です。
- 学習履歴がない状態では意味弱点モードは空です。通常学習で誤答が蓄積すると自動的に形成されます。
- v21の問題文・正答・誤答3個・重要度・出典は変更していません。v22では意味情報と復習ロジックのみ追加しています。

### 意味ベクトルについて
今回のベクトルはTransformer型の外部Embedding APIではなく、教材全体からローカルに構築した潜在意味ベクトルです。したがって通信・API費用・個人データ送信は発生しません。意味ベクトル単独で「理解度」を決めるのではなく、実際の誤答履歴・混同ペア・教材メタデータと組み合わせて使います。

詳細は `SEMANTIC_AUDIT_v22.md` と `IMPLEMENTATION_LOG.md` を参照してください。
