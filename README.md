# 公共一問一答 PWA — 学習エンジン v21

『公共一問一答』を4択形式で学習するPWAです。重要度別・分野別学習、検索、シャッフル、学習履歴保存に対応しています。

## 演習操作
問題演習中に必要な操作は **4択の選択だけ** です。回答すると正誤を短時間表示し、自動で次の問題へ進みます。2回連続正答で自動的に「習熟」、不正解で連続正答数は0に戻ります。

## GitHub Pages で更新する手順
1. このフォルダの中身を、GitHub Pages 用リポジトリのルートに上書きアップロードします。
2. `index.html`、`app.js`、`cards.json`、`sw.js` を含む **全ファイル** をコミットします。v21では教材データを `cards.json` に分離しているため、旧版の `index.html` だけを更新する方法は使えません。
3. Pages のデプロイ完了後、iPhoneの Safari で公開URLを一度開きます。
4. その後、ホーム画面版PWAを完全終了して再起動します。
5. v13以前から更新する場合、最初の起動後に一度PWAを完全終了して再起動してください。旧画面が残る場合のみ、ホーム画面アイコンを削除してSafariから再度「ホーム画面に追加」してください。学習履歴は旧 `localStorage` からIndexedDBへ自動移行します。

公開URLは通常 `https://<ユーザー名>.github.io/<リポジトリ名>/` です。


## v9 誤答選択肢の全面再設計
- 全1,925問について、誤答3個を事前計算してカードデータに固定しました。端末上で無関係語をランダム生成しません。
- 誤答語はすべて『公共一問一答』内に実際に登場する解答語から選んでいます。外部知識で新しい用語を捏造していません。
- 同一分野、設問文の類似度、語の種類（人物・法律・権利・条約・機関・著書・事件・場所など）、語尾（「〜原則」「〜法」「〜権」など）を組み合わせて候補を選びます。
- 複数回答問題は、翻訳・別名の組は対応関係を崩さず、列挙問題は原則として正答の一部だけを同系統語に置き換えた「紛らわしい近接誤答」にしました。
- 4択内の重複、正答と誤答の一致、複数回答の項目数不一致を全問検査しています。
- Service Worker は v9 です。


## v10 誤答選択肢の全面再設計
- 1,925問すべての4択を再生成・再監査しました。
- 誤答は「同じ分野」だけでなく、設問の要求する答えの種類（人物・著書・法律・制度・権利・裁判所・事件・国／地域など）を優先して選びます。
- 問題文の類似度、同一分野、原資料上の近接性、答えの語形を組み合わせ、意味的に近い誤答を優先しました。
- 複数回答問題は、著書の組・人物の組・国の組・外国語と日本語の対応・条文空欄などの構造を区別し、同じ構造の選択肢になるよう修正しました。
- エリクソンの発達課題、憲法条文、BRICS、外交原則、国際経済など、機械的な置換で不自然になりやすい問題は個別に調整しました。
- 正答との重複、誤答同士の重複、複数回答問題の項目数不一致は0件です。

## v13 最終誤答監査

## v21 学習エンジン更新
- 回答後の自動遷移を永続状態機械化し、iPhoneでのバックグラウンド復帰時にも整合します。
- Service Worker更新は学習中に強制reloadせず、安全なタイミングで切り替えます。
- 問題データを `cards.json` に構造化分離しました。
- 2連続正答=習熟を維持し、習熟後に自動定着確認（1/3/7/21/45日）を行います。
- 誤答ノート、混同ペア、誤答選択統計を端末内で記録します。
- 正答位置をセッションごとに変え、位置暗記を抑えます。
- 不正解時に短い訂正フィードバックを表示します。
- 学習履歴をIndexedDB中心へ移行し、旧履歴は初回起動時に自動移行します。
